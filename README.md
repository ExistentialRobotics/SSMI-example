### Introduction
This is the demo repository of [SSMI](https://github.com/ExistentialRobotics/SSMI.git) in ROS2


### Docker 
Use dockerfile in docker folder and download ROS2 SSMI to your local files, then mount it by specifing the path in docker-compose.yml.
